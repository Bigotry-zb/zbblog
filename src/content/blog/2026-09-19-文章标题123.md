在这里开始写正文。
1、VSCode ctrl+`  输入：npm run new -- "文章标题"，会在 src/content/blog/ 生成 2026-09-19-文章标题.md，自带 frontmatter（默认 draft: true）
2、编辑内容
    文件名决定 URL：/blog/2026-09-19-文章标题/，想短一点就手动改文件名（建议英文/拼音，如 jvm-gc.md）
    图片放 public/images/，正文用 ![说明](/images/xxx.png)
    小技巧：draft: true 时本地能看到、线上不会出现；写完把 draft 删掉或改 false 即可上线。
3、npm run dev                       # 预览，draft 文章也能看到
npm run build                     # 构建（draft 会被排除）
git add -A; git commit -m "post: 文章标题"; git push
